# AutoService CRM

Система управления заявками автосервиса.

## Возможности

- Регистрация пользователей
- Авторизация
- Создание заявок на обслуживание
- Просмотр заявок
- Административная панель
- Управление статусами заявок
- Система отзывов

## Технологии

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## Запуск

pip install -r requirements.txt

python app.py
